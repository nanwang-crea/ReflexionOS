## Decision

Call the plan tool ONLY if the task clearly needs 3 or more distinct execution steps,
such as multi-file implementation, debugging investigation, or a risky refactor.

If the task can be answered or completed directly (1–2 steps, simple question, single
file edit, quick lookup), respond with exactly and only the word: NO_PLAN
- Do NOT add any explanation, punctuation, or extra text after NO_PLAN
- Do NOT describe why no plan is needed
- Do NOT output anything other than the single token NO_PLAN

## When creating a plan

- Call the plan tool with a goal and the full steps list
- Set the first step's status to in_progress, all others to pending
- Use concise, high-level steps
- Do not explain the plan in normal text
- Do not include code or implementation details in the step text
