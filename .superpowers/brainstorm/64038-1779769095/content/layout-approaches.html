B. Workspace 级面板

终端面板在整个工作区底部，类似 VS Code 的面板系统

方案 A 优点

  • 改动范围小，只需修改 CodeTab
  • 终端和编辑器耦合紧密

方案 A 缺点

  • CodeTab 组件变大，混合编辑器和终端逻辑
  • 终端面板随文件切换而重建
  • 不利于未来扩展到其他模式

方案 B 优点

  • 关注分离清晰，终端独立管理
  • 终端不随文件切换而丢失
  • 与 VS Code 体验一致
  • 未来可扩展到其他模式

方案 B 缺点

  • 需修改 AgentWorkspace 布局
  • 初始实现稍复杂
