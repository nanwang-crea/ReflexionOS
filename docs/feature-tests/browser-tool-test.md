## 一、前置准备

### 1.1 安装依赖

```bash
cd backend
pip install playwright==1.49.1
playwright install chromium
```

### 1.2 启动服务

```bash
# 终端 1 — 后端
cd backend
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# 终端 2 — 前端
cd frontend
pnpm dev
```
